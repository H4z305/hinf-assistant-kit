# Overview

This is a second brain built on the `claude-obsidian` pattern in PARA mode.
Drop a source into `.raw/` and say "ingest [filename]"; ask questions and get
answers cited to your own notes; run "lint the wiki" every 10–15 ingests.

- `wiki/projects/` — active work with a deadline and an outcome
- `wiki/areas/` — ongoing responsibilities, no end date
- `wiki/resources/` — reference material by topic
- `wiki/archives/` — finished / closed work

See [[index]] for the full catalog and [[getting-started]] for daily commands.
